# 2車線ラウンドアバウトの合流制御

issue #5「OTRPの2車線ラウンドアバウト向けに合流優先と進入制御を検討する」の実装メモ。

## 譲れ（合流優先）

交差点の1マス手前にある一方通行標識に「この先の交差点で譲る」を設定すると、
その標識から交差点へ入る車（バス・トラックと市内車）は、ほかの道から交差点へ近づく車がいる間は待つ。

- 待つ相手は、交差点につながるほかの道の上で、交差点へ向かって動いている車。
  止まっている車は待たない（環道が詰まっているときに互いに待ち合うのを避けるため）。
- 相手の出口が自分と違うとき、または相手の出口が分からないときは、必ず待つ。
- 出口が同じときは、車線が重なるときだけ待つ。
  - 右折（左側通行なら左折）で入る車は手前の車線にだけ入り、直進は両方の車線を横切るものとみなす。
  - 相手が車線変更中なら車線は重なるものとみなす。
- 見る範囲は交差点に隣り合う1マス。`debug.set_merge_yield_lookahead(n)` で3マスまで広げられる（比較用。ネットワークゲームでは変えられない）。
- 設定は標識の `choose_sign_flag` の1ビット（`merge_yield`）に入るので、セーブ形式は変わらない。
  変更は `TOOL_CHANGE_ROADSIGN` の `y` で行うため、ネットワークゲームでも同期する。

### 設定のしかた

- ゲーム内: 一方通行標識の情報ウィンドウで「この先の交差点で譲る」を押す。標識の次のマスが交差点のときだけ表示される。
- スクリプト: `command_x.set_merge_yield(player, pos, 1)`、確認は `tile.find_object(mo_roadsign).is_merge_yield()`。
- 自分の標識（または所有者のいない標識）だけ変えられる。公共プレイヤーはすべて変えられる。

## 出口の空き確認

交差点の1マス手前の一方通行標識に「交差点の先に編成が収まるときだけ進入する」を設定すると、
その標識から交差点へ入る編成（バス・トラック）は、交差点の先に編成が止まれる場所が空いているときだけ進入する。

- 経路に沿って交差点の先を見て、交差点ではないマスが編成の長さ（併結中は併結全体の長さ）だけ続く所を探す。
  そこまでに止まっている車があれば待つ。動いている車は待たない。
- 編成の長さに加えて8マス先まで見ても見つからないとき（小さな環道を回り続けるときなど）や、経路が終わるときは待たない。
- 両方向に走る道路では、対向車線を逆向きに走る車は数えない。
- 市内車には適用しない。
- 設定は譲れと同じ標識の別のビット（`merge_exit_clear`）に入り、譲れと同時に使える。
  ゲーム内は同じ情報ウィンドウ、ツールは `TOOL_CHANGE_ROADSIGN` の `x`、スクリプトは `command_x.set_merge_exit_clear(player, pos, 1)` と `is_merge_exit_clear()`。

### 既存の先読みで防げないケース

既存の進入判定は、進入する交差点の先を3マスまでしか見ない。その3マスがすべて交差点だと、先で止まっている車に気づかずに進入し、
交差点の上で止まってしまう。テスト（`test_roundabout_exit_*`）では、交差点が4つ続く道路の先でバスが満載待ちをしている所へ、
脇道から別のバスを入らせて再現している。設定がないとバスは交差点上で止まり、設定があると標識の手前で待つ。

### 長い編成

テスト用の pak64 の道路車両は連結の制約が厳しく、2マス以上の編成を作れない（試した連結はどれも車庫から出発できなかった）。
そこで、制約のない1マス長の試験用車両 `TestLongBus` を `tests/long-road-vehicle/` に置き、2両つないだ2マスの編成で確かめた。

- 交差点が1つだけの道路で、交差点の先に1マス空けてバスが満載待ちをしている所へ、脇道から2マスの編成を入らせる。
- 設定がないと、既存の判定は交差点の次の1マスが空いているので進入し、編成の後ろを交差点に残したまま待つ（`addon_roundabout_long_tail_on_junction_by_default`）。
- 設定があると標識の手前で待ち、交差点に残らない（`addon_roundabout_long_exit_clear_keeps_junction_free`）。編成の長さを1マスとして扱うように壊すと、この確認は落ちる。

試験用車両は CI のテスト環境に入っていないので、この2つは `all_tests` に入れていない。手元では次のように走らせる。

```
makeobj pak64 <テスト環境>/pak/vehicle.TestLongBus.pak tests/long-road-vehicle/test_long_bus.dat
tests/run-automated-tests.sh addon_roundabout_long_tail_on_junction_by_default
tests/run-automated-tests.sh addon_roundabout_long_exit_clear_keeps_junction_free
```

試験用車両はほかのテストの車両選びを変えるおそれがあるので、ふだんのテスト環境とは別のコピーに入れる。

## 一括設定ツール

`TOOL_SETUP_ROUNDABOUT`（一般ツールの57番）は、4×4の範囲を2点で選ぶと、その外周の環道の入口をまとめて設定する。

- まず全体を調べ、問題があれば何も変えずにエラーを返す。
  - 範囲がちょうど4×4であること。
  - 外周の12マスがすべて道路で、通行方向にだけ回れること（右側通行なら反時計回り、左側通行なら時計回り）。
  - 環道へ入れる道路が1本以上あること。
  - 環道につながる道路が、入る方向か出る方向の片方にしか走れないこと（両方に走れる道路に一方通行標識を置くと出口がふさがるため）。
  - 外周の道路と入口の道路が、自分・公共・所有者なしのいずれかであること（手作業で標識を置ける道路と同じ）。
  - 入口の手前のマスに一方通行標識を置けること（行き止まりや踏切でないこと、一方通行以外の標識がないこと）。
  - 新しく置く標識の代金を払えること。
- 次に、入口の手前のマスに一方通行標識がなければ置き（使える一方通行標識のうち最も安いもの）、
  すべての入口の標識に、ツールの指定どおり譲れと出口の空き確認を設定する。指定しなかったほうは外す。
- 環道や枝道の道路そのもの（一方通行の向きや車線）は変えない。
- 取り消しはない。設定は標識に入っているので、標識を撤去するとその入口の設定もなくなる。
  入口を増やしたときは、もう一度ツールを使えば新しい入口にも設定される（すでにある標識はそのまま使い、設定だけ揃える）。
- 設定は標識に入るので、ネットワークゲームでも同期する。

ツールの指定（`default_param`）は、`y` が譲れ、`x` が出口の空き確認で、両方なら `yx`。
メニューに置くときは menuconf.tab に `general_tool[57]` を書く（このツールのアイコンは pak にないので、キーを割り当てて使う）。
スクリプトからは `command_x(tool_setup_roundabout).work(player, 角1, 角2, "yx")` で使える。

## 計測

自動テストから使う計測用の関数を `debug` クラスに置いている。カウンタはセーブされず、ゲームの動きにも影響しない。

| 関数 | 内容 |
|---|---|
| `debug.set_merge_stats_enabled(bool)` | 計測の開始・停止 |
| `debug.reset_merge_stats()` | カウンタと車線の通過数を0に戻す |
| `debug.get_merge_stat(name)` | カウンタを読む。知らない名前なら -1 |
| `debug.watch_lane_passes(pos)` / `debug.get_lane_passes(pos, passing)` | マスに入った車を車線ごとに数える |

カウンタ名: `enter_checks` `enter_time_us` `citycar_checks` `citycar_time_us` `yield_checks` `yield_waits` `yield_time_us` `exit_checks` `exit_waits` `exit_time_us`

### 試験用の環道

`tests/automated-tests/tests/test_roundabout.nut` の `_ra_build()` が、4×4 の反時計回りの環道（x,y = 6〜9）と、
4方向の枝道（それぞれ折り返しループ付き）を作る。道はすべて一方通行の2車線（`oneway_mode`）。

ベンチマーク（`bench_roundabout_*`）は CI の対象外で、手元で次のように走らせる。

```
tests/run-automated-tests.sh bench_roundabout_uniform
```

`BENCH` で始まる行に、出口ごとの通過数、環道の車線ごとの通過数、流入ごとの最長待ち時間、計測カウンタが出る。
